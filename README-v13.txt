枝记 v13 使用说明

双击“枝记.exe”启动，保持“程序文件”目录完整。
软件使用紫色笔记页与嫩芽图标，启动程序和任务栏使用同款图标。
在软件右上角“…”菜单点击“创建桌面快捷方式”，即可从桌面启动。
快捷方式指向当前软件目录；之后移动软件目录，需要重新创建快捷方式。
若桌面已有同名快捷方式且指向其他路径，会另建“枝记（新版）”，不会覆盖原快捷方式。

“我的笔记”保存笔记、图片、格式和回收站，更新时保留此目录。
“缓存”保存窗口缓存，“程序文件”保存软件本体和运行组件。
首次启动新目录时会复制旧版 AppData 笔记（若存在），已有 notes.json 不会覆盖。
从 v12 升级请把本包的枝记.exe 和程序文件复制到原来的软件目录，保留原“我的笔记”。
运行前请先关闭旧版本，以免两版同时编辑同一份笔记。

这个原始 ZIP 不包含个人笔记，可以直接发给别人。
不要把使用后含有“我的笔记”数据的文件夹整体发给别人。
需要迁移到自己的电脑时，关闭软件后复制整个文件夹即可。

需要 64 位 Windows 10/11、.NET Framework 4.6.2+ 与 Microsoft Edge WebView2 Runtime。
运行时下载：https://developer.microsoft.com/microsoft-edge/webview2/
第三方许可位于“程序文件”。
